# Weekly Meal Planner 🍽️

A simple and elegant web application to plan your meals for the entire week. Add meals for each day, view your complete schedule, and keep track of what you're eating!

## Features ✨

- 📅 **Weekly Planning**: Plan meals for all 7 days of the week
- 💾 **Local Storage**: Your meal plan is automatically saved in your browser
- 🎨 **Beautiful UI**: Modern, responsive design with gradient colors
- 🗑️ **Easy Management**: Delete meals with one click
- ⌨️ **Quick Input**: Press Enter to quickly add meals
- 📱 **Mobile Friendly**: Works perfectly on all device sizes

## How to Use 🚀

1. **Select a Day**: Choose a day from the dropdown menu
2. **Enter a Meal**: Type your meal name in the input field
3. **Add Meal**: Click "Add Meal" button or press Enter
4. **View Schedule**: See all your meals organized by day
5. **Delete Meals**: Remove meals by clicking the Delete button

## Installation 💻

1. Clone the repository:
   ```bash
   git clone https://github.com/abhijithis581/weekly-meal-planner.git
   ```

2. Navigate to the project directory:
   ```bash
   cd weekly-meal-planner
   ```

3. Open `index.html` in your web browser or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

## Features Breakdown 🎯

### Data Persistence
- Your meal plans are saved automatically using browser's LocalStorage
- Your data persists even after closing and reopening the browser

### User-Friendly Interface
- Smooth animations and hover effects
- Responsive design that works on desktop, tablet, and mobile
- Clear visual hierarchy with gradient colors

### Keyboard Support
- Press Enter key to quickly add meals without clicking the button
- Tab navigation for accessibility

## Tips & Tricks 💡

- Plan your week ahead for better meal prep
- Use specific meal names (e.g., "Grilled Chicken with Rice" instead of just "Chicken")
- Clear your browser's LocalStorage if you want to start fresh
- Customize the colors in `style.css` to match your preference
